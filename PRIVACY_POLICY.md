# Privacy Policy & User Manual (GDPR Compliant)

**Effective Date:** February 28, 2026
**Project:** Memory Cards Game (University Project)

## 1. Introduction
This document outlines how the "Memory Cards Game" handles user data. As a client-side application built for educational purposes, we prioritize data minimisation and user privacy in accordance with GDPR standards.

## 2. Data Storage Technologies
We do not use any external servers to store your personal information. All data remains on your local device using:
* **HTTP Cookies:** For session management and UI settings.
* **Local Storage:** For game statistics and history.

## 3. Cookie Configuration (Transparency)
According to GDPR, we classify our storage as follows:

| Name | Type | Purpose | Duration |
| :--- | :--- | :--- | :--- |
| `session_user` | Essential | Stores the current logged-in user's profile. | 7 Days |
| `settings_[user]` | Essential | Stores game difficulty, card speed, and mode. | 30 Days |
| `memory_game_consent_status` | Essential | Remembers your choice in the cookie banner. | 365 Days |
| `gameResults_[user]` | Statistics | (Local Storage) Stores game moves, time, and dates. | Persistent |

## 4. User Rights (GDPR)
Users have full control over their data:
* **Right to Access:** All stored data is visible on the "Profile" and "Results" pages.
* **Right to Erasure:** You can clear game results via the "Clear" button in the app or by clearing your browser's cache.
* **Right to Withdraw Consent:** You can reset your cookie preferences at any time via the "Privacy Policy" page.

## 5. User Instructions
1.  **Start:** Navigate to the Home page and click "Start Game".
2.  **Authentication:** You can register/login to have personalized settings and results.
3.  **Gameplay:** Flip cards to find pairs. The game ends when all pairs are found.
4.  **Settings:** Adjust the difficulty and card flip speed in the "Settings" menu.
5.  **Privacy:** Use the Cookie Banner to allow or deny statistics tracking.
